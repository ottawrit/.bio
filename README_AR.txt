حزمة Taourirt Bio المحسّنة لمحركات البحث

محتويات الحزمة:
- index.html: الصفحة الرئيسية المحدّثة، مع روابط تفاصيل المنتجات وصورة مشاركة اجتماعية.
- products/: أربع صفحات مستقلة، صفحة لكل منتج، وبداخل كل صفحة صورة المنتج وبيانات Product المنظمة.
- sitemap.xml: خريطة روابط الصفحات الخمس.
- robots.txt: يسمح بالزحف ويشير إلى خريطة الموقع.

طريقة النشر:
1) فك ضغط الملف.
2) افتح مستودع GitHub الخاص بالموقع.
3) استبدل index.html الموجود بالنسخة الجديدة.
4) ارفع مجلد products كاملاً مع الملفات الأربعة داخله.
5) ارفع sitemap.xml و robots.txt إلى جذر المستودع بجانب index.html.
6) نفّذ Commit changes وانتظر نشر GitHub Pages.
7) في Google Search Console أرسل خريطة الموقع: https://ottawrit.github.io/.bio/sitemap.xml
8) افحص كل صفحة منتج بأداة Rich Results Test واطلب الفهرسة من Search Console.

ملاحظة: لم نضف تقييمات أو سياسات شحن/إرجاع غير مؤكدة. ظهور الصور والنتائج الغنية قرار تتخذه Google ولا يمكن ضمانه فور النشر.
